Backwash Decision

  • Backwash when PSI is 8–10 above baseline
  • Typical clean baseline: 10–15 PSI
  • After backwash: run Rinse 15–30 sec
  • D.E.: add fresh D.E. after every backwash
  • ⛔ Never backwash cartridge filter

Equipment Pad Components

  • Pump — heart of circulation
  • Strainer basket — clean every visit
  • Filter — sand / D.E. / cartridge
  • Pressure gauge — record baseline
  • Heater — check for errors/noise
  • Timeclock — verify setting
  • Shut-off valves — note position

Pump Runtime

  • Summer: 8–12 hours/day
  • Off-season: 6–8 hours/day
  • Check timeclock at every visit
  • Report grinding/screeching sounds
